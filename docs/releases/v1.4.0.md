# v1.4.0 — Pi、Oh My Pi 与 OpenCode 新版兼容

新增 Pi 和 Oh My Pi（omp）会话管理，支持查看、搜索、详情、单选及批量删除，并沿用删除预览、可选备份、异常回滚和进程检查。

- **Pi**：识别默认目录、环境变量和用户设置指定的会话目录，支持 JSONL v1–v3、重命名、自定义 ID 和空会话。
- **Oh My Pi**：识别固定标题槽、自定义会话指针和终端指针；清理会话正文、附属文件、已识别的提示历史、标题、摘要、全文搜索和统计索引。
- **OpenCode**：兼容 `session_v2` 和新旧表共存的数据库，补齐新版正文、收件箱、指令状态、blob 引用及 job 记录。保留自动化定义和共享 blob，校验父子与派生依赖。文件消失时提供具体路径和重新预览提示。
- **Codex / Cursor**：包含自 v1.3.2 以来的 Codex 双目录库、活动会话及状态关联表支持，以及 Cursor SSH 远端 Agent 本地缓存适配。

提供 Windows x64、macOS Apple Silicon（arm64）和 macOS Intel（x86_64）三个独立安装包。Windows 解压后运行 `AIConversationCleaner.exe`；macOS 解压后运行 `AIConversationCleaner.app`。打包程序自带 Python 运行时。

发布流程分别在三个目标平台运行测试、构建程序，并使用虚构数据验证 OpenCode、Pi、Oh My Pi 的读取、预览、直接删除和备份删除；同时检查 CLI 进程保护。macOS 安装包解压后还会验证临时签名。SHA-256 校验文件随安装包提供。

删除前请退出对应应用；Pi 与 Oh My Pi 可能共用会话文件，因此会检查两者的进程。默认不备份，需要保留恢复副本时请选择“备份到指定目录”。不会删除配置、凭据、Skills、项目文件、共享 blobs、已有备份或云端会话。Oh My Pi 命名 profile、压缩归档和远端存储不在本次适配范围内。

本版本仍为公开预览版。Windows 程序没有数字签名，macOS 使用临时签名，未做 Apple 公证。内部存储格式可能随上游升级变化，未知关联结构会阻止删除，详细范围见 README。

## English

Adds Pi and Oh My Pi tabs, custom local session discovery, JSONL previews, selected deletion and recognized Oh My Pi history/FTS/statistics cleanup. OpenCode now supports `session_v2` alongside legacy storage, with dependency checks and missing-file diagnostics. This release also includes Codex and Cursor compatibility improvements made since v1.3.2.

Windows x64, macOS arm64 and macOS x86_64 packages are built and exercised on their respective CI runners using synthetic data. Existing backup, rollback and offline-writer protections apply. Shared blobs, credentials, settings, skills, project files and remote histories remain outside deletion scope. See the README for supported versions and limitations.
