新增 macOS 支持，Windows 与 Mac 共用七个应用适配器、中文界面及备份/删除流程。本版本继续作为公开预览版发布。

## 下载

| 系统 | 下载文件 |
| --- | --- |
| macOS Apple Silicon（M 系列芯片） | `AIConversationCleaner-macOS-arm64.zip` |
| macOS Intel | `AIConversationCleaner-macOS-x86_64.zip` |
| Windows x64 | `AIConversationCleaner-Windows-x64.zip` |

解压后运行 `AIConversationCleaner.app`（Mac）或 `AIConversationCleaner.exe`（Windows），无需另装 Python 或 Node.js。`SHA256SUMS.txt` 包含三个下载包的校验值。

## 本次更新

- 使用 macOS 原生应用数据目录，适配 Cursor、Antigravity 及默认备份位置。
- 支持原生目录选择、Finder 打开备份、Mac 路径显示和桌面启动时的 Codex CLI 定位。
- 支持 macOS 应用、Electron 辅助进程及已知 Node/Bun 启动方式的运行检测；检查失败时阻止删除。
- 增加双击源码启动入口 `源码启动.command`，提供 Apple Silicon 和 Intel 独立应用包。
- 修复 Codex 历史数据库备份被误识别为活动数据库的问题，保留历史备份不动。
- 改进跨进程操作锁，同时运行多个清理器时正确阻止冲突操作并给出提示。
- 三个平台均在 GitHub Actions 中执行测试、构建和隔离数据验证，macOS 另验证解压后的应用签名。

Windows 程序未签名；macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证，首次打开可能受到系统限制。请核验校验值并参阅项目 README 的运行说明。

使用前退出目标应用及其后台进程，建议先体验演示模式，并保留默认备份。不同上游应用版本的内部数据格式可能变化。
