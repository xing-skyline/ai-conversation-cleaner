更新 Cursor 3.23、Antigravity 2.19 和 DeepSeek Harness 2.x 的本地会话清理支持。本版本继续作为公开预览版发布。

## 下载

| 系统 | 下载文件 |
| --- | --- |
| Windows x64 | `AIConversationCleaner-Windows-x64.zip` |
| macOS Apple Silicon（M 系列芯片） | `AIConversationCleaner-macOS-arm64.zip` |
| macOS Intel | `AIConversationCleaner-macOS-x86_64.zip` |

解压后运行 `AIConversationCleaner.exe`（Windows）或 `AIConversationCleaner.app`（Mac），无需另装 Python 或 Node.js。`SHA256SUMS.txt` 包含三个下载包的校验值。已使用旧版程序的用户需要重新下载并替换程序；更新源码不会更新原有 EXE 或 `.app`。

## 本次更新

- **Cursor**：适配新版会话头、草稿、独立消息、检查点、差异记录和本地全文搜索库，显示搜索库或所属数据键中的残留记录。按原生格式保留删除标记，保留同 ID 的云端搜索缓存和跨会话共享内容。删除后核对实际数据与索引残留。已在 Windows Cursor 3.23.23 的隔离数据副本上验证。
- **Antigravity**：支持 2.x 独立会话数据库及其 WAL/SHM、Hub 摘要和已有 IDE 索引；支持一致性备份、失败回滚和残留验证。已核验 Windows 2.19.1 的存储结构。
- **DeepSeek Harness**：支持 2.x 会话目录、压缩日志和置顶引用，识别摘要缓存版本 3–7；提示用户退出可能驻留后台的 DSH Desktop。
- **备份选项**：默认不备份；需要时选择“备份到指定目录”。这些此前仅在源码中的改动一并纳入本次下载包。
- **打包验证**：在 Windows、Apple Silicon 和 Intel 构建中，使用隔离虚构数据检查 Cursor 列表读取、删除、备份、原生删除标记以及未选会话和云端缓存的保留。

使用前退出目标应用及其后台进程。建议先体验演示模式；希望保留恢复副本时，请在删除前选择“备份到指定目录”。上游内部数据格式可能继续变化，未适配结构会阻止部分清理操作。

Windows 程序未签名；macOS 应用仅使用 ad-hoc 签名，未进行 Apple Developer ID 签名或公证。请核验校验值并参阅项目 README 的运行说明。

Packages include the previously source-only optional-backup changes and use synthetic Cursor smoke tests on all three platforms. Cursor 3.23.23 storage was verified on isolated Windows copies. Replace older executables or app bundles with this release; pulling source alone does not update them. This remains a public preview.
