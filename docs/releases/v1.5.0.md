# v1.5.0 — 删除时可选择关闭应用

删除确认框新增“关闭对应应用后继续删除”，每次预览默认不勾选。勾选后仅关闭预览中列出的对应应用进程，等待退出，再执行原有的备份、删除与核验。

- Windows 先请求窗口关闭，macOS 先发送退出信号；未及时退出的已确认进程会被强制结束。正在进行的任务会中断，未保存内容可能丢失，请先保存工作。
- 显示待关闭的进程名称和 PID。不会按通用 Node/Bun 名称批量结束进程，也不会结束整个终端或任意子进程。
- 关闭失败、新进程启动、进程身份改变或会话数据改变时停止删除，提示重新预览。清理器自身及启动它的上级进程受到保护。
- 未勾选时保留原行为：可以浏览正在运行的应用，但必须手动退出后才能删除。
- Pi 与 Oh My Pi 可能共享会话文件，因此两个应用的相关进程都会列入确认范围。

继续支持 Codex、Claude Code、Grok Build、Cursor、Antigravity、DeepSeek Harness、OpenCode、Pi 和 Oh My Pi；保留 v1.4.0 的 OpenCode 新旧数据库兼容与 Pi/Oh My Pi 会话清理。

提供 Windows x64、macOS Apple Silicon 和 macOS Intel 安装包。macOS 应用使用临时签名，未公证。
